With data acquisition functionality via the Arduino and Python scripts, the mic sensor and CNC machine data need to be stored in real time for later computation and machine learning tasks. Amazon’s DynamoDB is the appropriate application to accomplish this. Figure 4 below shows the main page for Task 3 DynamoDB. The database table was configured with “timestamp (Number)” as the Partition Key. To store the collected data in the database, a rule action was added to the message routing rule configured in Task 2 to send the JSON data to the database. Figure 5 below displays this. An IAM role also had to be created to grant the message routing rule access to the DynamoDB, shown in Figure 5. From here, we are ready to collect and store data in the database for analysis and machine-learning training in later tasks.
