Building on what was discovered in task 1, the next step is to use a large-sound-sensor microphone to collect data from the CNC machine and then upload it to the IoT core. The device in question was an Arduino with a large-diaphragm microphone, but there were many problems with this concept, such as the microphone only working when blown on and when the machine was either cutting or traveling. Pubsub file will extract the necessary data from the IP and upload it to the IoT core via MQTT. The microphone captured the necessary data every 1.5 seconds to ensure it was recorded properly.
