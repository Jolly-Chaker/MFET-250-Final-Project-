For Task 4, we conducted a test to collect actual data from the CNC machine as it executed a program to perform roughing and finishing facing operations. While the CNC machine was running, we ran our Python script to collect mic sensor and machine data (such as coordinate positions, spindle speed and status, feed rates, etc.) and publish it in JSON format to both an MQTT test client and the DynamoDB table. The data was sampled approximately every 1.5 seconds, so we had enough data for analysis later, but also so we didn’t have an overwhelming amount of data as if we had a higher sampling rate.
