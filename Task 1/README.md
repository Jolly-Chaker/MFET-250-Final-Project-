The goal was to design a system architecture that would enable seamless data flow from point A to point B. First, the CNC machine will send its data to the MTConnect client and to the Arduino simultaneously. Once the data has been sent to both systems, it will be combined into a single file in VS Code to produce the output. The VSCode file will be uploaded to a connected device on AWS IoT Core, which will then upload it to an assigned database. Finally, the data from the database can then be exported to an Excel file for easier viewing. See Figure 1 for the flow chart
